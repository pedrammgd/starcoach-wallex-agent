# پیام آماده برای پشتیبانی Wallex / برگزارکننده — ارسال نشده

سلام، برای چالش Wallex استارکوچ، طرح اختصاصی ۵٬۰۰۰٬۰۰۰ تومانی برای نمایندهٔ تیم تأمین شده است. ربات فعلاً shadow است و هیچ سفارش واقعی ارسال نکرده‌ایم.

در ۲۳ اکتبر۲۰۲۶، کلید API در `GET /v1/account/fee` پاسخ200 داد. `GET /sub-accounts` یک حساب با نام هکاتون، نوعprop، فعال و غیرمعلق نشان داد و `GET /v1/account/balances-detail` با header مستند `sub-account-client-id` برای همان حساب، total/available=5000000 TMN و freeze=0 برگرداند. اما `GET /v1/prop/user/packages/history` و `GET /v1/prop/user/packages/active` (دومی با همان header) پاسخ401 می‌دهند. آخرین چرخه16:39ایران بود. بنابراین کلید globally invalid نیست و مشکل scope یا قرارداد سرویس اعتبار باید روشن شود. شناسهٔ کامل/کلید را در پیام عمومی ننوشته‌ایم؛ در صورت نیاز شناسه را فقط داخل پنل امن خودتان ارائه می‌کنیم و API key را ارسال نمی‌کنیم.

لطفاً کتبی تأیید کنید:

۱. endpoint و header/بدنهٔ دقیق ثبت، لغو و تطبیق سفارش روی **همان حساب اعتباری هکاتون** چیست؟ آیا باید کلید مستقل زیرحساب استفاده شود؟ آیا `sub-account-client-id` در POST سفارش لازم/پشتیبانی‌شده است؟ `client_id` سفارش را با شناسهٔ حساب مخلوط نمی‌کنیم.
۲. راه مستند احراز اینکه کلید دقیقاً به طرح هکاتون تعلق دارد و تمام fillها/feeها فقط در کیف پول اختصاصی ثبت می‌شوند چیست؟
۳. شناسهٔ عمومی پکیج، فهرست کامل بازارهای مجاز و محدودیت‌های خاص مسابقه چیست؟ آیا `unavailableMarkets` همان محدودیت نهایی چالش است؟
۴. maker/taker، واحد کارمزد، حداقل notional/quantity، precision، محدودیت نوع سفارش و هر هزینهٔ اعتبار ویژهٔ این طرح چیست؟
۵. زمان دقیق شروع و پایان معاملات و cutoff تبدیل نهایی به تومان با تاریخ و timezone چیست؟ مهلت ارسال پروژه نیز لطفاً جداگانه با timezone اعلام شود. سه روز را از زمان فعال‌سازی حساب محاسبه نکرده‌ایم.

تا تأیید مسیر حساب، بازارها، هزینه‌ها و cutoff و مجوز مستقل صاحب حساب، معاملهٔ زنده غیرفعال می‌ماند. هیچ سفارش آزمایشی برای کشف کیف پول ثبت نمی‌کنیم و به برداشت/انتقال نیاز نداریم.
