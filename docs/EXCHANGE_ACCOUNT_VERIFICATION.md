# وضعیت احراز حساب و API

وضعیت: BLOCKED — کلید و هویت حساب اختصاصی رقابت دریافت/احراز نشده است. تأمین وجه طبق اعلام کاربر پذیرفته است؛ به‌معنای احراز scope کلید نیست.

از فایل عمومی مستند رسمی اعتبار فعلی تأیید شد: هر حساب اعتباری کیف پول، API Key و تاریخچهٔ سفارش جدا دارد. مستند قدیمی با مسیر `/trade-credit/intro` در ابزار وب 404 می‌دهد؛ سایت فعلی routeهای `/docs/trade-credit-intro` و فایل‌های chunk عمومی دارد. گزیده‌ها در OFFICIAL_API_EXTRACTS.md ثبت شده‌اند. اشارهٔ مستند به معامله در اسپات، به‌تنهایی تطبیق کلید با حساب هکاتون را اثبات نمی‌کند.

فهرست عمومی `/v1/markets` واقعاً پاسخ داد (۳۷۳ بازار در snapshot). `stepSize` تعداد اعشار حجم و `tickSize` تعداد اعشار قیمت است. BTCTMN حداقل ۵۰هزار تومان دارد؛ این تأیید بازار مجاز مسابقه نیست. تاریخچه `/v1/udf/history` نیز واقعاً دریافت شد. هیچ endpoint خصوصی فراخوانی نشده است.

پیش از توسعهٔ adapter تولیدی باید قرارداد رسمی فعلی حساب اختصاصی، شناسهٔ طرح هکاتون، scope و permission کلید اختصاصی، fee asset/coefficient، فهرست مجاز و ساعت پایان معاملات تأیید شود. کلید حساب اصلی نباید برای کشف حساب رقابت بدون محدودهٔ روشن استفاده شود. endpoint MCP رسمی احراز نشده؛ مخزن شخص ثالث به‌عنوان MCP رسمی نصب نشده است.

Executor فقط با broker تزریقی simulation کار می‌کند و intent را پیش از submit ثبت می‌کند. timeout باعث UNKNOWN است؛ lookup و reconciliation لازم است. missing lookup مجوز retry نیست؛ partial fill و fee تجمعی باید یکنواخت باشند. adapter واقعی عمداً موجود نیست.
