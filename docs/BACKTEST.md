# بک‌تست و حدود شواهد

فرمان بازتولید: `.venv/bin/python scripts/benchmark_all.py`.

دادهٔ OHLCV عمومی واقعی، ۱۸۰ روز منتهی به 2026-10-22T21:00:00Z درخواست شد. ۴۳۱۹ کندل BTC و ETH و ۴۳۰۳ کندل USDT موجود بود. یک ساعت در دادهٔ BTC/ETH غایب است. USDT شکاف‌های بیشتری دارد. `data/quality_report.json` زمان دقیق و hash قطعات را ثبت می‌کند. قطعه‌های کمتر از ۵۰۰ کندل برای benchmark کنار گذاشته شده‌اند. نمونه‌گیری بر اساس پیوستگی و حداقل طول است؛ نتایج تجمیع‌شدهٔ کل ۱۸۰ روز ادعا نمی‌شود.

API در پنجره‌های ۱۰۰۰ساعته تقریباً ۶۹۷ کندل آخر را برگرداند؛ پنجرهٔ ۵۰۰کندلی مشکل truncation را رفع کرد. فایل‌های اولیهٔ `_1h_segment_` فقط تشخیصی بودند و در benchmark نهایی استفاده نمی‌شوند. فایل‌های `_validated_segment_` منبع معتبر پژوهش‌اند. فایل‌های raw پاسخ‌های اصلی و زمان دریافت را نگه می‌دارند.

تقسیم زمانی: ۵۰٪ warm/train، ۲۵٪ validation و ۲۵٪ holdout. مدل آنلاین در holdout فقط labelهای گذشتهٔ بالغ‌شده را یاد می‌گیرد؛ frozen model نیست. سه fold با تاریخچهٔ درحال‌گسترش نیز گزارش می‌شود. holdout برای انتخاب یا تنظیم پارامتر مصرف نمی‌شود. نتایج سایر نامزدها در آن تشخیصی است.

کارمزد هر سمت ۳۰bp، spread کامل ۱۰bp، slippage هر سمت ۱۰bp: هزینهٔ تقریبی رفت‌وبرگشت ۰٫۹٪. این‌ها فرض‌اند؛ هزینهٔ واقعی اعتبار هنوز معلوم نیست. سناریوی صفرهزینه و دوبرابر هزینه جداست. اول تصمیم پایان کندل و سپس open کندل بعدی؛ ظرفیت فقط بر حجم قبلی. partial fill با محدودیت حجم و گردکردن شبیه‌سازی می‌شود؛ صف سفارش و depth واقعی تاریخی نداریم.

تمام انتخاب‌های validation فعلی cash بوده‌اند. AI محلی به‌دلیل gate هزینه هیچ ورودی نداشته؛ اثر مثبت مالی AI اثبات نشده است. نمونهٔ سود momentum در holdout قابل تعمیم به آینده یا سرمایهٔ واقعی نیست. `net_return` شامل mark موجودی باز است؛ `realized_pnl_TMN` جداست؛ `liquidation_estimate_return` فقط برآورد است و fill محسوب نمی‌شود. Sharpe صرفاً توصیفی و بدون تصحیح وابستگی زمانی است.

خروجی هر اجرا: manifest با data/config/source hashes، summary.csv، equity.csv، نمودار SVG و تصمیم‌های JSONL. Git مستقل موجود نیست؛ source hash جایگزین ادعای SHA ساختگی شده است.
