# گزارش مرحلهٔ BoxAPI — ۱ آبان ۱۴۰۵

BoxAPI تنها LLM فعال است. SDK رسمی OpenAI نسخهٔ 3.37.0 نصب و قفل شده و Gemini با حفظ کد و کلید از مسیر فعال خارج است. تنظیمات، doctor، shadow، بررسی دسترسی و ابزار Liara به BoxAPI متصل‌اند. هیچ سفارش، برداشت، انتقال، خرید منابع یا deploy واقعی انجام نشده است.

۵۶ تست آفلاین در محیط پروژه و یک محیط مجازی پاک گذشتند. pip check در محیط پاک بومی ARM نیز موفق بود. آزمون HTTP شبیه‌سازی‌شدهٔ SDK مسیر، schema، token usage، retry محدود، timeout بدون تکرار، رد خروجی ناقص، تأثیر ENTER/EXIT بر shadow و وتوی مستقل ریسک را پوشش می‌دهد. آزمون اجرای پاک خطای نبود پوشهٔ گزارش را پیدا کرد؛ پیش از نتیجهٔ نهایی اصلاح شد. uv نصب‌شده تحت x86 نسبت به wheelهای ARM هشدار platform می‌داد؛ نصب و بررسی نهایی با Python بومی در محیط پاک انجام شد.

بدون کلید، هر دو مسیر مستند BoxAPI در GET /models پاسخ ۴۰۱ دادند. `verify-boxapi --online` با placeholder به MISSING_KEY و صفر درخواست شبکه رسید. هیچ استنتاج واقعی BoxAPI، هزینهٔ واقعی یا برتری مدل تأیید نشده است. مدل اولیه gpt-5.4-mini فقط کاندیداست. پس از درج کلید، فرمان مستند دو نمونهٔ ساختاریافته از حداکثر دو مدل مجاز می‌گیرد و latency، مصرف توکن و تصمیم‌ها را ثبت می‌کند. خروجی نامعتبر، مصرف توکن نامشخص یا ENTER بدون edge از انتخاب مدل کنار گذاشته می‌شود. هزینهٔ gateway بدون نرخ/واحد معتبر به USD تبدیل نمی‌شود.

مقایسهٔ جدید ۳۶ حالت شامل سه preset، سه استراتژی، دو سناریوی کارمزد و دو بازار BTC/ETH بود. هر بازار ۱۸۲ کندل validation داشت؛ holdout به موتور مقایسه داده نشد. هیچ گزینهٔ دارای حداقل دو fill و سود مثبت در هر دو سناریوی هزینه پذیرفته نشد؛ انتخاب هر دو بازار cash با بازده صفر بود. بهترین گزینهٔ معامله‌گر در هزینهٔ پایه برای BTC حدود منفی ۰٫۲۱۶۹٪ و برای ETH حدود منفی ۰٫۴۴۹۸٪ بازده validation داشت. این داده‌ها قبلاً بررسی شده‌اند و این گزارش مدعی holdout مستقل جدید نیست. این نتایج به LLM واقعی نسبت داده نمی‌شوند.

چرخهٔ سایهٔ عمومی نسخهٔ نهایی BTCTMN با دادهٔ واقعی ثبت شد: نبود momentum edge، هدف صفر، بدون fill، موجودی مجازی پنج میلیون تومان، دو event و زنجیرهٔ hash معتبر. به علت نبود کاندیدا، استنتاجی فراخوانی نشد. این شواهد صحت اجرای سفارش واقعی یا سودآوری را اثبات نمی‌کنند.

Liara CLI رسمی 9.6.0 موجود است. فرمان‌های بررسی catalog و استنتاج محدود از runtime آماده‌اند، ولی حساب/تیم/اپ هدف مشخص نشده‌اند و اتصال منطقهٔ استقرار تأیید نشده است. هویت و route حساب اعتباری والکس، فهرست بازارهای مجاز، کارمزد حساب و پایان دقیق معاملات همچنان احراز نشده‌اند. تأیید صریح live نیز دریافت نشده و broker واقعی عمداً مسدود است.

راهنمای درج کلید و فرمان‌ها: BOXAPI_SETUP_FA.md. لاگ‌های تست، sweep و shadow در reports/boxapi_* قرار دارند. بستهٔ بازبینی با whitelist و بررسی نبود کلیدهای محلی ساخته می‌شود؛ این بسته ارسال مسابقه یا نسخهٔ production معامله‌کننده نیست.
